# TR · 한글 문서와 AI 사이의 교두보

GPT나 Claude에 한글 문서를 맡길 때, 내용을 고친 뒤에도 원래의 표와 그림, 단과 조판을 살려서 HWP로 돌려받고 싶었습니다. 그래서 한글 문서와 AI 사이에 **TR**이라는 교두보를 만들었습니다.

TR은 AI가 읽을 Markdown을 만들고, AI가 돌려준 편집 JSON을 한글 문서에 반영합니다. 파일을 고르고 저장 위치를 반복해서 찾던 초기 버전에서 출발해, 이제는 파일을 끌어놓는 방식으로 작업할 수 있습니다. 화면은 연보라색으로 꾸미고, 어느 단계에서 무슨 일이 일어났는지 하단 작업 기록에서 확인할 수 있게 했습니다.

## 사용하기

Windows, Python 3.11 이상(Tkinter 포함), 데스크톱 한컴오피스 한글이 필요합니다. 프로젝트 파일을 같은 폴더에 두고 `Start-TR.cmd`를 실행하세요.

1. **원본 한글**에 HWP를 놓으면 바탕화면에 `원본명_TR` 프로젝트가 만들어집니다.
2. 가운데 `AI용.md`를 ChatGPT나 Claude에 끌어넣고 바꾸고 싶은 내용만 말합니다. 다운로드 가능한 편집 JSON을 생성하라는 지시는 Markdown에 들어 있습니다.
3. 내려받은 JSON을 **AI의 편집 결과**에 놓습니다. TR이 프로젝트를 찾아 새 HWP로 저장합니다.
4. 결과 카드를 클릭해 편집본을 열거나 탐색기로 끌어갑니다.

[자세한 사용법](./사용법.md)

## 지원하는 편집

문구 바꾸기·삭제, 글자 서식, 문단 삽입·삭제와 정렬, 단과 여백 변경, 새 구역 삽입, 표 셀 수정과 표 삽입, PNG/JPEG 삽입·교체, 일부 개체 삭제를 지원합니다. HWP 결과는 데스크톱 한글 엔진으로 저장합니다. TR의 로컬 변환에는 API 키가 필요하지 않습니다.

한글 2018에서 HWP 결과를 다시 열어 텍스트와 조판을 확인했고, HWPX 출력도 검증했습니다. 한글의 세부 편집 기능 가운데 아직 연결하지 않은 명령이 있으며, 입력 형식과 그 안에 들어 있는 기능에 따라 왕복 결과가 달라질 수 있습니다.

## 개발 기록

제작에는 **GPT 6.1 Sol**을 사용했습니다. [개발 기록](./개발기록.md)에 HWP 변환 실험, 편집 기능 확장, 드래그 화면을 만든 과정을 정리했습니다. 앞으로 한글에서 직접 실행할 수 있는 편집 기능을 조금씩 더 연결해 보려고 합니다.
